# 画面デザイン

このサイトには2つのデザインがあり、いつでも切り替えられる。

| 名前 | 内容 | 状態 |
|---|---|---|
| `techo`（おやこ手帳） | 2026-10-18 採用。丸ゴシック、クリーム地、主催者の種類で色分けした表形式の一覧 | いまの既定 |
| `classic` | 2026-10-17 までのデザイン。濃い緑のヘッダー、表形式の一覧 | 残してある |

## 切り替え方
- **元のデザインに戻す**：`design.js` の `DESIGN_DEFAULT` を `"classic"` に書き換えて公開する。
- **その場だけ見比べる**：URL の末尾に `?design=classic`（または `?design=techo`）を付ける。保存はされない。
- **採用前の状態そのもの**：ブランチ `design-classic`（コミット 6911cda）。ファイル一式をこの時点に戻したいときに使う。ただし大会データも当時のものなので、ふだんは上の `DESIGN_DEFAULT` で戻す。

## ファイルの分担
- `style.css`：classic のスタイル。両方のデザインの土台で、techo のために書き換えない（`.techo-only` を隠す1行だけ追加）。
- `techo.css`：techo の上書き。すべて `[data-design="techo"]` の中だけで効く。
- `design.js`：どちらのデザインかを決め、`<html data-design="…">` を付ける。techo のときは M PLUS Rounded 1c を読み込む。
- `app.js`：`TECHO` が真のときだけ、主催者の種類の絞り込みを使い、表の行（`row` / `mapRow`）と詳細に主催者の種類の色と名前を付ける。
- `map.js`：techo のときだけ、ピンの色を主催者の種類に合わせる。
- `index.html`：techo だけで使う部品には `techo-only` を付けてある（classic では表示されない）。

## techo（おやこ手帳）の決めごと
- 色：地 `#fffdf7`、文字 `#1d2a44`（紺）、強調 `#f6c343`（黄）、締切 `#e2574c`（さんご）。暗い画面設定では紺地に切り替わる。
- 文字：M PLUS Rounded 1c。
- ロゴ：黄色の角丸の中に、紺の線で描いたカレンダーとゴルフボール。`techo.css` の `h1::before` と、ブラウザのタブに出る `favicon.svg` が同じ絵。2026-10-18 に旗の絵から変更（ゴルフ用品店の旗のロゴを思わせるため）。旗は使わない。
- 上から順に：サイト名 → キャッチ「今週の申込、わすれていませんか？」と数字のステッカー（申込受付中・まもなく／これからの大会／日程発表待ち） → タブと絞り込み → 主催者の種類 → 各タブの中身。
- 2026-10-18 の採用時は上部に「今週の手帳」と「もうすぐ締切」があったが、同日ユーザー指示で取り除いた。
- 一覧と地図の横の一覧：classic と同じ表形式（開催日・大会名・会場・主催・申込）。行の左端の色と、主催欄の上の小さな札で主催者の種類を示す。大会名を押すと詳細が開く。
  - 2026-10-18 に一度カード形式で公開したが、見にくいとのことで同日に表形式へ戻した。
- スマホ：一覧の行は classic と同じく縦に積む。地図の横の一覧は枠の中でスクロール。

### 主催者の種類（7分類）
主催者欄の先頭の団体で決める（「共催」「主管」「後援」などのかっこ書きは見ない）。判定は `app.js` の `orgType`。

| キー | 表示名 | 例 | 色 |
|---|---|---|---|
| jjga | JJGA | 日本ジュニアゴルフ協会 | 青 `#1d5fa8` |
| junior | ジュニアツアー・育成 | JJGT、IJGA、キッズゴルフチャレンジ | 青緑 `#00796b` |
| union | ゴルフ連盟・協会 | JGA、地区連盟、都道府県のゴルフ協会・連盟 | 緑 `#3b6b1f` |
| school | 学校ゴルフ連盟 | 高ゴ連、地区・府県の高等学校・中学校ゴルフ連盟 | 紫 `#6a47a8` |
| media | 新聞・テレビ・出版 | スポーツニッポン新聞社、ゴルフダイジェスト社、地方紙、放送局 | 茶 `#a35c00` |
| pro | プロ団体 | JLPGA、PGA、JGTO | 赤紫 `#b0306a` |
| other | 企業・ゴルフ場・自治体 | 協賛企業、ゴルフ場、練習場、市町村 | 灰 `#56636e` |

### ロゴ枠
- 主催者名に英字の略称（JJGA、JJGT、KHGA など）があれば略称を、なければ種類の記号を出す。
- 主催者の公式ロゴは各団体の権利物なので、載せるのは許諾が取れた団体だけにする。

## classic の決めごと
- 色：地 `#fafaf8`、文字 `#141414`、ヘッダー `#0f1f18`、受付中 `#0b5d3b`。文字は Noto Sans JP と Inter（数字）。
- 一覧は月ごとの表（開催日・大会名・会場・主催・申込）。スマホでは行を縦に積む。

## 提案資料
`docs/design/proposals/` に、検討した案の画面（第1回のA〜D案、第2回の改訂A・C・D案と部品一覧）の元ファイルを残してある。これらはデザイン用キャンバスの形式で、そのままブラウザで開いても正しく表示されない。
